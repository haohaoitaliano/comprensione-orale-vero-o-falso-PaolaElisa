# Comprensione orale – Vero o falso?

Esercizio di ascolto mobile-first con 8 domande Vero/Falso.

## Anteprima locale

È possibile aprire direttamente `index.html` nel browser oppure avviare un server statico locale:

```sh
python3 -m http.server 8000
```

Poi visita `http://localhost:8000`.

## Audio

Inserisci il file audio completo in `audio/dialogo-paola-elisa.mp3`.
